🎪 Sistem Pemesanan Lapak Sederhana

Sistem Pemesanan Lapak Sederhana adalah aplikasi web yang dirancang untuk memfasilitasi pemesanan lapak (stand/booth) secara online, cocok untuk acara bazaar, pameran, atau pasar. Aplikasi ini memiliki dua peran utama: **Pengguna** (untuk memesan lapak) dan **Admin** (untuk mengelola lapak dan pesanan).

✨ Fitur Utama

* **Pemesanan Lapak Online:** Pengguna dapat melihat lapak yang tersedia dan melakukan pemesanan.
* **Otentikasi Pengguna:** Login dan Register untuk pengguna.
* **Manajemen Lapak (Admin):** Admin dapat menambah, mengubah, dan menghapus lapak, serta memperbarui statusnya.
* **Manajemen Pesanan (Admin):** Admin dapat melihat daftar pesanan yang masuk dan melakukan tindakan (misalnya, menghapus/menyetujui).
